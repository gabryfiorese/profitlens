# ProfitLens

A web calculator that estimates net profit, fees, break-even price and suggested selling price for resale / dropshipping items.

## Why
Sellers often price from "cost vs sale" and forget platform fees, payment fees, shipping, packaging and tax buffers. ProfitLens turns those hidden costs into clear numbers.

## Features
- Net profit, margin and ROI from a single sale price
- Break-even price and suggested price for a target profit
- Configurable platform / payment / tax fees (percent + fixed)
- Loss and low-margin warnings
- Typed calculation core covered by unit tests
- Responsive two-column UI

## Tech stack
React 19 · TypeScript · Vite · Vitest
